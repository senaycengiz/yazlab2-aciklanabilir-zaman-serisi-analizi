# YAZLAB2 - Açıklanabilir Zaman Serisi Analizi

## Proje Amacı
Bu projede zaman serisi verileri üzerinde derin öğrenme tabanlı black-box modeller ile olasılıksal otomata tabanlı açıklanabilir modeller karşılaştırılacaktır.

## Proje Konusu
Proje kapsamında zaman serisi verilerinde anomali tespiti yapılacaktır. LSTM, GRU veya 1D-CNN gibi derin öğrenme modelleri ile PAA, SAX ve sliding window tabanlı olasılıksal otomata modeli karşılaştırılacaktır.
